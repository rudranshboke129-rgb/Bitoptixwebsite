BITOPTIX STATIC HTML WEBSITE

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the folder BitOptix-Static-HTML.
3. Double-click index.html.
4. The website will open in Chrome or your default browser.

No Node.js, npm, database, or terminal is required.

TO EDIT:
Open the folder in VS Code. Edit HTML files, assets/css/style.css and assets/js/main.js.
